# Source research brief (shared by all 5 source agents) — 2026-11-17

Project: Salsa Search, an app that shows where you can actually partner-dance salsa in a city (socials, classes, schools, hostel nights). Goal of this research: for each data source, figure out how it can help FIND places to dance salsa in a city, CHECK them, and capture VIBE, and how it hands off to the other sources (e.g. Google place → website → Instagram).

Agents and their files (docs/brain/sources/<source>.md):
- src-listing → listing-sites.md (Salsavida and similar event sites)
- src-google → google-places.md (Places search/details, plus venue websites and link pages like Linktree)
- src-instagram → instagram.md
- src-facebook → facebook.md (pages, photos/flyers, events, groups)
- src-reddit → reddit.md

## Rules for every agent
- Read for context: docs/brain/interviews/owner-workflows.md, docs/brain/data-access.md, docs/research/data-sources.md.
- Do NOT open any other interview, any answer key, or anything under docs/brain/pilots/.
- Practice only on cities outside the test set (Puerto Escondido, Cusco, Lima, Mexico City, Cali). Use Ho Chi Minh City plus one other city of your choice.
- Public pages and official docs only: no logins, no accounts, no API keys, nothing paid. Check access rules and terms against official pages and link them. Mark anything unverified.
- Write no app code, touch nothing under frontend/, run no git commands. Write only your own file.

## Each file contains
1. What the source gives
2. How to get it: costs, limits, terms (with links)
3. What it's good for: finding, checking, or vibe
4. Its noise and how to filter it
5. How it hands off to the other sources
6. One worked example on a practice city

## When your file is done
Read the other agents' files that exist, and message the other src-* agents (SendMessage) to agree on how the sources fit together. Note agreements and disagreements in a short "Fit with other sources" section at the end of your file. Then message discovery-strategist that your file is ready. Final reply to the main session: under 8 lines.
