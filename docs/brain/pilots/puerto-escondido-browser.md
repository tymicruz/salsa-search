## D. Method report

**What Instagram gave that plain web search didn't**
- The real account behind an existing listing (@pmesdepuromovimiento) and its **current** schedule and prices. SalsaVida had the nights wrong or incomplete.
- Dated evidence of activity. Post ages are shown ("23w", "69w", "16w"), which lets you judge whether a place is still running.
- Bios with one-line schedules (Congo: "sólo los miércoles").
- Tag-following worked: the Grupo Fiebre post led to a venue (Juana Mezcala), and the Plaza de la Bachata post led to teachers' names and a related community account.
- Instagram did **not** surface the main local school. I did not find a dedicated school account.

**What Reddit added**: nothing. It is unreachable here and Google did not return it either.

**What was hard or impossible**
- Not logged in: profile headers and individual post/reel pages (caption + comments) open, but the post grid shows only about 3 items behind a login popup. So I could only read posts whose links I already had or that the grid exposed.
- Stories and highlights: only highlight titles are readable, not content.
- Some handles and posts return "isn't available" (@pmlacasadelbailador, the Mándala post). Unclear whether that is a wrong handle or a gate.
- Instagram keyword search needs login, so I could not search for "salsa Puerto Escondido" on Instagram itself.
- Bio text is cut off at "more".
- Facebook, which locals clearly use for recommendations, appeared only as snippets.
- Google Maps search worked for DC earlier in this session; I did not rerun it for Puerto Escondido.

**Is it worth automating?** Partly.
- Yes for: following known account links, reading current schedule posts, and dating activity. That fixed the biggest errors in the earlier blind test.
- Limit: discovery of hidden places depends on a logged-in session (grid, search, stories). Without it, you only find what other pages already point to.
- Staleness check is cheap and valuable: post age separates active from dead.
- Facebook and Reddit need a different approach.
