## H. Method report
**What Instagram gave beyond plain web search**
- The aggregator flyer (whole-city schedule, only in image form).
- Real, current handles and bios; sanity checks on SalsaVida (it had a wrong handle and a conflicting Tuesday venue).
- Prices, times and venue changes (XSalsa's Friday), plus class timetable and pricing from La Pachanga's flyer.
- Collab tags that show who works with whom (La Pachanga × bachatainsaigon, My House × Salsa Thursdays).

**What Reddit added**: nothing. The browser pane refuses reddit.com, and search/fetch don't return Reddit threads. I did not route around that. Treat Reddit as untested for this city.

**What was hard**
- Schedules live in image flyers, not captions. Vision reading works but small print (prices on dense tables) is error-prone. Verify numbers.
- Grid thumbnails sometimes load blank; need wait/scroll.
- Highlights and stories (where "Calendario"-type schedules often live) not read, to avoid view traces. For automation, check whether the scraper can read them.
- Conflicting sources are the norm (Tuesday venue, Friday venue). A pipeline needs "latest dated source wins" plus conflict flags.
- Facebook and Google Maps (reviews, ratings) not covered in this run.

**Is it worth automating?** Yes for the seed → handle → recent posts → vision-read flyers steps; this run is evidence the content is there and meaningful. I did the equivalent of about 7 accounts in the pane with manual clicking, which is slow but works. The valuable part to automate is: (1) find the city's aggregator account(s) by Google/hashtag, (2) pull ~12 latest posts for every handle found, (3) vision-read flyers, (4) reconcile against listing sites with a conflict flag. A paid scraper is only needed for step 2 at scale, and I can't tell from here whether it returns highlights. Test that on one account before paying.
